# Secure File Management System

A Python-based application designed for secure file handling and management.

##  Features
* Secure file upload and storage.
* Server-side processing using Python.
* Simple web interface (`index.html`).

##  Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Divya-Rag/Secure-File-Management-System.git](https://github.com/Divya-Rag/Secure-File-Management-System.git)
   cd Secure-File-Management-System

2. **Install dependencies:**
   pip install -r requirements.txt

3. **Usage**
To start the server, run:
  -- python server.py
Then, open your browser and navigate to http://localhost:5000 (or the port specified in your script).
